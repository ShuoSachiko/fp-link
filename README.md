# fp Link

适马 fp 的非官方安卓 USB 联机工具。按机身快门拍照，自动保存到平板，并可送入像素蛋糕精修。

## 使用

1. 下载并安装 [APK](./fp-link-0.3.0.apk)，平板需支持 USB OTG。
2. 相机设为 **STILL / JPEG**，USB 模式选择 **相机操控**，用数据线连接平板。
3. 打开 fp Link，点圆形连接键，允许 USB 访问，等待连接就绪。
4. 如需自动送图，先安装像素蛋糕，再选择其 **精修入口**，允许悬浮窗权限并开启自动送图。
5. 按相机快门，等上一张接收完成后再拍下一张。点击悬浮窗可暂停送图。

照片保存在相册 `Pictures/FpBridge`，按 `FP0001.jpg` 连续编号。

已验证普通 SIGMA fp 固件 5.02。自动送图只负责打开照片，不自动套预设或导出。本项目与 SIGMA、像素蛋糕无官方关联。
